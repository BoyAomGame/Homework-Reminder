# เตือนการบ้านผ่าน Discord (โฮสต์เอง)

เว็บจัดการการบ้านและตารางเรียนสำหรับ **ผู้ใช้หนึ่งคน** พร้อมบอต Discord ที่รับข้อความส่วนตัวภาษาไทยหรืออังกฤษเพื่อเพิ่ม ดู แก้ไข และปิดงาน ระบบส่งข้อความเตือนก่อนกำหนดส่งและแจ้งเมื่อเลยกำหนด ตั้งค่าบอต โมเดล AI และเวลาแจ้งเตือนทั้งหมดผ่านหน้าเว็บ **ไม่ต้องสร้าง `.env`**

## สิ่งที่ต้องมี

- Docker Engine และ Docker Compose รุ่นที่รองรับคำสั่ง `docker compose`
- บอตที่สร้างใน [Discord Developer Portal](https://discord.com/developers/applications) หากต้องการใช้คำสั่งและการแจ้งเตือนทาง Discord
- API Key ของบริการที่รองรับ OpenAI Chat Completions หากต้องการให้บอตเข้าใจข้อความอิสระ; การนำเข้าตารางเรียนจากรูปต้องใช้โมเดลที่อ่านภาพได้

## ติดตั้ง

1. ดาวน์โหลดโครงการและเปิดเทอร์มินัลในโฟลเดอร์นี้
2. เริ่มบริการ:

   ```sh
   docker compose up -d --build
   ```

3. เปิด <http://localhost:8000/register> แล้วสร้างบัญชีเจ้าของระบบด้วยอีเมลและรหัสผ่านอย่างน้อย 8 ตัวอักษร **สร้างได้เพียงบัญชีแรก** หลังจากนั้นหน้าสมัครจะพาไปหน้าเข้าสู่ระบบ
4. เปิดหน้า **ตั้งค่า** แล้วกรอก URL, ชื่อโมเดล และ API Key สำหรับอ่านข้อความ ค่าเริ่มต้นของ URL/โมเดลคือ DeepSeek (`https://api.deepseek.com/v1`, `deepseek-chat`) API Key ถูกเข้ารหัสก่อนเก็บและจะไม่แสดงกลับ หากเปลี่ยนค่าบนหน้าเว็บ บอตจะใช้ค่าใหม่ทันที
5. หากต้องการนำเข้าตารางเรียนจากรูป ให้กรอกชื่อโมเดลอ่านภาพ และ URL/API Key ของบริการนั้นด้วย ช่อง URL หรือ API Key ของภาพที่เว้นว่างจะใช้ค่าของบริการข้อความ

ไฟล์ฐานข้อมูล SQLite และกุญแจเข้ารหัสอยู่ใน Docker volume `homework_data` และอยู่ต่อหลังรีสตาร์ตหรือสร้างคอนเทนเนอร์ใหม่ ควรสำรอง **ทั้ง volume** เพื่อให้ยังอ่านโทเคนบอตและ API Key ที่เข้ารหัสไว้ได้ อย่าลบ volume ด้วยคำสั่ง `docker compose down -v` หากต้องการเก็บข้อมูล

## ตั้งค่าบอต Discord

1. สร้าง Application และ Bot ที่ Discord Developer Portal แล้วเปิด **Message Content Intent** ในหน้า Bot
2. คัดลอก Bot Token ไปวางในหน้า **ตั้งค่า → บอต Discord** โทเคนจะถูกเข้ารหัสและไม่แสดงอีก
3. ส่งข้อความส่วนตัว (DM) ถึงบอตด้วย **รหัสเชื่อมบัญชี** ที่แสดงในหน้าเว็บ หากเปิด DM ไม่ได้ ให้เชิญบอตเข้าเซิร์ฟเวอร์ที่บัญชีของคุณอยู่ก่อน ระบบจะรับคำสั่งผ่าน DM เท่านั้น เมื่อเชื่อมแล้วบอตรับคำสั่งจากบัญชี Discord นี้เท่านั้น
4. ลองส่ง เช่น `การบ้านเลข หน้า 5 ส่งวันศุกร์`, `เหลืออะไรบ้าง`, `ทำการบ้านเลขเสร็จแล้ว`, `เปลี่ยนเวลาส่งเลขเป็น 08:30`, `ลบอันเคมี` หรือ `ช่วยเหลือ`

หากบอตขึ้นสถานะมีปัญหา ตรวจโทเคนและ Message Content Intent หากยังไม่ตั้ง API Key ข้อความ บอตจะเชื่อมต่อได้แต่ประมวลผลคำสั่งภาษาธรรมชาติไม่ได้

## ใช้งานหน้าเว็บ

- **การบ้าน:** เพิ่ม แก้ไข ทำเครื่องหมายเสร็จ และลบงาน ใส่วันที่ส่งและเวลา (หากไม่ใส่เวลา จะนับสิ้นวันตามเวลาไทย)
- **ตารางเรียน:** เพิ่มคาบและเวลาตามวัน หรืออัปโหลดรูปแล้วตรวจแก้แต่ละแถวก่อนยืนยัน การยืนยันรูปจะแทนตารางเดิมทั้งหมด
- **ตั้งค่า:** กำหนดเวลาที่ให้เตือนเป็นจำนวนนาทีก่อนส่ง เช่น `1440, 180, 0` หมายถึง 1 วัน, 3 ชั่วโมง และตรงเวลา
- งานที่เลยกำหนดจะมีการแจ้งเตือนซ้ำได้สูงสุด 3 ครั้ง ห่างกันอย่างน้อย 24 ชั่วโมงเมื่อส่ง DM สำเร็จ

## การเปิดให้ใช้จากภายนอก

ค่าเริ่มต้นของ Compose เปิดเว็บเฉพาะ `127.0.0.1:8000` บนเครื่องโฮสต์ หากจะใช้จากอินเทอร์เน็ต ให้ตั้ง reverse proxy พร้อม HTTPS ชี้มาที่พอร์ตนี้ และสร้างบัญชีเจ้าของระบบก่อนเปิดให้บุคคลภายนอกเข้าถึง ตัวอย่างส่วน `location` ของ Nginx:

```nginx
location / {
    proxy_pass http://127.0.0.1:8000;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
    client_max_body_size 10m;
}
```

หาก reverse proxy อยู่คนละเครื่อง ให้ปรับ `ports` ใน `compose.yaml` และจำกัดการเข้าถึงด้วยไฟร์วอลล์ตามเครือข่ายของคุณ บริการนี้ต้องรัน **คอนเทนเนอร์และ worker เดียว** เพราะบอต Discord และตัวตั้งเวลาเตือนทำงานอยู่ในโปรเซสเดียวกัน

## ดูแลระบบ

```sh
docker compose logs -f homework-reminder   # ดูบันทึกการทำงาน
docker compose restart                     # เริ่มใหม่
docker compose down                        # หยุดโดยเก็บข้อมูล
docker compose up -d --build                # อัปเดตโค้ดและเริ่มใหม่
```

สำหรับการพัฒนาหรือทดสอบในเครื่อง ใช้ Python 3.11+ ติดตั้ง `requirements.txt` แล้วรัน `pytest` การติดตั้งด้วย Docker ไม่ต้องใช้ PostgreSQL หรือไฟล์ `.env`
